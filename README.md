Windows 支持后台下载更新，点击“重启并安装”后升级。macOS 下载后退出应用，将新版拖入“应用程序”并替换。Ubuntu 下载后退出应用，在下载目录运行 `sudo apt install ./PaperEnjoyer-0.4.0-Linux-amd64.deb` 安装或升级；应用菜单中打开 PaperEnjoyer，使用 `sudo apt remove paper-enjoyer` 卸载。已有资料库和设置会保留。

安装包暂未使用商业代码签名证书。请按操作系统提示确认发行来源；macOS 首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

Release 中的 SHA256SUMS 文件可用于校验下载完整性。
